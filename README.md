# Family tree viewer

An interactive family-history viewer built with React, TypeScript and Vite. It draws a family as a tree, a fan chart and a map, and keeps track of **how sure** each fact is.

> **All data in this repository is fictional.** The Hartwell, Lindqvist and Moreau families are invented for the demo. Real towns are used only so the map has something to show.

## What it does

- **Tree view.** Pick a person as the centre and open parents, siblings and children one step at a time. Couples are drawn as one unit and children hang from a shared junction.
- **Fan view.** Direct ancestors in rings around the centre person.
- **Map view.** A built-in outline map (Natural Earth, public domain). It makes no requests to map providers. Pins are sized by the number of people and filtered by Born, Died, Lived, Married and Buried.
- **List and Sources.** A sortable table of everyone, and a gallery of documents and photographs grouped by person.
- **Confidence levels.** Every link and fact carries its basis (record, database entry, family account, inference). The interface reduces that to Confirmed, Probable or Possible, shown by line style and a small mark on the box. Conflicting versions of a fact are shown side by side and never silently resolved.
- **Local first.** No analytics, no web fonts and no CDN. The page loads only its own files.

## Run it

You need Node 20 or later.

```bash
cd app
npm install
npm run dev        # http://127.0.0.1:5173/
```

A production build:

```bash
npm run build && npm run preview
```

## Data

The app reads plain JSON from `app/public/data/`: `people`, `relationships`, `facts`, `sources`, `documents`, `conflicts`, `questions`, `places`, `spelling` and `notes`. The types are in [`app/src/types.ts`](app/src/types.ts).

The sample data is generated by [`scripts/make_sample_data.py`](scripts/make_sample_data.py), which is a short example of how the files fit together. To use your own family, replace the JSON files with yours.

**If you use real data, keep it out of public repositories.** Living people's names and birth dates are sensitive, and git history is permanent. The `.gitignore` here already excludes the folders where real photographs and scans would go.

## Optional feedback button

The Feedback button posts to `/api/feedback`. In development a small in-memory stand-in handles it. For a deployed site, `app/worker/index.js` is a Cloudflare Worker that stores messages in KV. See `app/wrangler.example.jsonc`.

## Project layout

```
app/src/        React components and pure layout code (layout.ts, fan.ts, kinship.ts)
app/public/     data/*.json, the map outline, sample scans
app/worker/     optional Cloudflare Worker for feedback
scripts/        sample-data generator
```
